# Trace forensics

1. Verify the artifact's provenance, workload, and relevant time window.
2. Query the existing artifact for the task's specific symptom and correlate it with source locations.
3. Record evidence references, limitations, and competing explanations; do not invent data absent from the trace.
4. Return the diagnosis as evidence for the parent to decide the next task. Request live-process work only through the parent if the existing artifact is insufficient and the scope allows it.
